Research Questions:
1. How accurately can machine learning models predict the outcomes of deep reinforcement learning algorithms in multi-agent settings, based on their hyperparameters and hardware?
2. How many training episodes (or how much training time) are required for cooperating agents to consistently push the block to the goal within a defined time limit?
3. Does the number of independent machine learning agents affect their performance when attempting to complete a task that requires collaboration?
